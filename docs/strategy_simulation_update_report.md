# 策略模拟实验中心更新报告（03 / 04 职责重构）

## 页面调整内容

### 03 策略模拟实验中心

| 项 | 调整 |
|----|------|
| 定位 | 负责「策略如何运行，智能体如何演化」；不强调最终效果数字 |
| 顶部说明 | 调整介入时机与传播链后，基于 PolicyAgent 模拟过程：主体行动、信息流动、知识状态变化 |
| 主流程 | **方案设计 → 传播过程模拟**（效果分析迁出） |
| 方案顺序 | 介入时机 → 传播链 → 传播目标 |
| 方案总结 | 运行前展示本次改变：时机 / 链 / 观察目标 |
| 运行交互 | 运行后收起方案设置，保留「查看方案」；重点展示过程模拟 |

### 04 效果分析与优化

| 项 | 调整 |
|----|------|
| 定位 | 负责「结果如何解释，策略如何优化」 |
| 结构 | **模拟结果 → 问题诊断 → 优化建议** |
| 承接数据 | 读取 03 写入的 `v3_cfg` / `v3_result`（session） |

侧栏实验路径同步为：02 机制 → 03 过程模拟 → 04 解释与优化。

## 新增 / 强化模块

### 03

1. **可解释传播时间轴**：Round × S1–S4；关键节点（权威解释、专业协同、媒体扩散、认知变化）
2. **节点详情**：事件名、Round、主体、行为、内容、信息流向、知识状态、机制解释 + 行为/作用/结果示例
3. **信息卡片**：来源 / 内容 / 策略 / 接收；优先真实文本案例，否则结构化说明
4. **Agent 三级展示**：现实解释（默认）→ 模型依据 → 高级原始参数

### 04

1. **模拟结果**：指标卡以「策略改变导致什么变化」解释为主，辅增益与 Reality 对照
2. **问题诊断**：相对 Reality 自动归纳优势 / 不足
3. **优化建议**：问题 → 原因 → 可操作的时机/传播链调整方向

## 数据来源

| 展示 | 来源 |
|------|------|
| 正式情景指标 | `data/scenario_results.json`（Indexed → 最近邻 S0–S3） |
| Reality 基线 | S0 指标与覆盖序列 |
| 过程演化节点 | UI（时机/链）+ `EVENTS` + 结果指标派生（展示层） |
| 信息卡片 / 群体回放 | `demo_data/simulation_trace.jsonl`（机制演示） |
| 真实文本案例 | `mechanism_narrative.load_text_examples`（既有案例包） |
| Agent 参数 | `behavior_decision_rules.json`（只读） |
| 诊断 / 优化文案 | 相对 S0 增益 + 时机/协同模板（展示层） |

## 是否影响模型

**否。**

- 未修改 Agent 核心参数与决策规则文件
- 未修改 Simulation 核心逻辑
- 未改写正式 S0–S3 结果
- 未新增研究变量；引擎仍仅开放介入时机档位与现实结构 / 多主体协同

传播链 UI 仍映射既有二元 `actor_collaboration`；传播目标仅改变观察重点。
