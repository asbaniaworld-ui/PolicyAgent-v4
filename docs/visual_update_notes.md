# visual_update_notes（v4）

## 雷达图

- **使用**：主体 5 维特征（原创/发布、转发、政策事实策略、问题质疑、跨主体互动），均来自已有 profiles/网络概率，统一到 0–1。
- tooltip 显示归一化值；维度数=5。

## 热力图

- 行=From 发起方，列=To 接收方；格内百分比；方向说明固定文案；底部结论由矩阵最大跨主体流自动生成。

## 时间轴

- 主轴为 Round；事件点+竖线；阶段底色分区；事件仅含 S1–S4 边界、提前解释、爆发锚点。

## 曲线填充

- Reality/Sim 之间使用中性浅灰差异带（避免一律绿色）；事件竖线与时间轴同名。

## 颜色与可访问性

- 改善=绿色，恶化=红色；Reality 灰虚线，Simulation 蓝实线；指标卡补充定义与来源提示。
