# 模拟可视化映射说明

说明策略模拟实验中心各可视化：**数据来源 → Agent 机制 → 研究意义**。均为既有 simulation / trace / 正式结果的展示映射，不引入新实验变量。

---

## 1. 方案设计区（介入时机 / 传播链 / 传播目标）

| 项 | 数据来源 | Agent 机制 | 研究意义 |
|----|----------|------------|----------|
| 介入时机 | `TIMING_OPTIONS` → `interpret_timing` / `interpret_start` | 权威解释进入环境的时间窗口 | 观察不同解释窗口对早期触达与后续理解的影响 |
| 传播链 | `CHAIN_PRESETS` → `actor_collaboration`（reality_structure / multi_actor_synergy） | 主体功能分工的表达层；引擎仅两档协同 | 比较现实结构 vs 多主体协同下的事实传递与多样性 |
| 传播目标 | `GOAL_DEFS`（仅评分/观察） | **不改**决策规则 | 明确本次结果应重点读哪个指标 |
| 方案总结 | 上述 UI 汇总 + `nearest_validated_scenario` | Indexed 时对齐已验证 S0–S3 | 让用户确认「改了什么」再运行 |

## 2. 可解释传播演化时间轴

| 节点类型 | 数据来源 | Agent 机制 | 研究意义 |
|----------|----------|------------|----------|
| 权威解释介入 | 时机映射 Round（early_14→75；real→89；early_7 展示锚点 82）+ EVENTS | 政府侧权威信息注入窗口 | 解释「何时进入认知窗口」 |
| 主体协同加入 | 链含 professional / multi_actor_synergy | 专业解释节点加入信息路径 | 说明协同如何改变事实供给 |
| 信息扩散节点 | EVENTS `s2_burst`（Round 89） | 媒体爆发与扩散加速 | 对齐媒体集中报道阶段 |
| 政策事实认知变化 | EVENTS `s3_feedback` + 终值指标 | 知识更新后事实掌握变化 | 从触达过渡到理解 |

节点详情字段（行为 / 信息变化 / 指标提示 / 机制）来自配置与既有指标，**非新仿真日志字段**。

图表：`fig_process_evolution`（`charts_v4.py`）。

## 4. 单智能体决策演示（过程模拟 · 深入）

| 步骤 | 数据来源 | Agent 机制 | 研究意义 |
|------|----------|------------|----------|

## 5. 效果指标卡（策略改变 → 变化）

| 指标 | 数据来源 | Agent / 过程机制 | 研究意义 |
|------|----------|------------------|----------|
| 权威信息早期触达 | `coverage_pre_burst`（情景表 / 运行结果） | 提前解释窗口扩大爆发前触达 | 策略是否改善早期信息触达 |
| 政策事实理解程度 | `fact_accuracy` | 焦点事实掌握阈值比例 | 策略是否改善理解（非仅曝光） |
| 传播效率（趋稳轮次） | `diffusion_round` | 覆盖连续稳定的首轮 | 扩散是否更快进入稳定 |
| 主体多样性 | `actor_diversity`（Shannon 熵） | 消息来源类型分布 | 参与结构是否更均衡 |

卡片文案：`strategy_effect_explanations` 结合时机/协同与相对 S0 增益（`format_gain`）。

## 7. Reality vs Simulation + 关键事件轴

| 元素 | 数据来源 | 机制 | 研究意义 |
|------|----------|------|----------|
| Simulation 实线 | `coverage_series_sim` 或终值锚定示意序列 | Indexed / Live 结果序列 | 策略条件下的路径 |
| Reality 虚线 | `coverage_series_reality` / S0 | 基线对照 | 相对 Reality 的差异 |
| 事件竖线 + 横排标签 | `EVENTS` | 阶段边界与实验介入锚点 | 判断策略影响落在哪些阶段 |
| 独立横向事件轴 | 同上 | hover 看 date/stage/desc | 不遮挡主曲线时的事件阅读 |
