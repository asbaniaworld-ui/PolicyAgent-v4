# 机制页设计更新说明（mechanism_page_design_update）

## 页面结构变化

原结构（Dashboard 倾向）：

```text
指标卡 → S0 基线画像 → 雷达图 → 热力图
```

新结构（案例与机制解读）：

```text
01 案例事件介绍（政策背景 / 数据窗 / 阶段）
 ↓
02 传播机制核心观察维度（先解释再给数，并接到模型）
 ↓
03 四类传播主体画像（角色 / 数据 / 文本案例 / Agent 抽象）
 ↓
04 主体间信息流向关系（From→To，澄清对角线）
 ↓
05 信息暴露机制（社会互动 + 公共热点）
 ↓
06 从传播机制到智能体模拟（流程桥接）
```

导航名称同步为「案例与机制解读」。主标题为「案例事件与政策传播机制解读」。

## 文案调整

- 去掉“本页面展示……”式说明，改为研究导入：案例是什么、数据从哪来、为何适合做 Agent、后续如何进实验。
- 模块之间增加桥接句，形成递进，避免模块孤立。
- 不再使用“影响热力图”措辞，改为「主体间信息流向关系」。

## 指标定义（观察维度）

| 展示名 | 字段 | 通俗含义 | 对 Agent/实验 |
|:--|:--|:--|:--|
| 权威信息早期触达 | coverage_pre_burst | 媒体爆发前政策信息触达程度 | 提前解释是否扩大认知窗口 |
| 政策事实理解程度 | fact_accuracy | 核心事实掌握程度 | 对应知识状态更新 |
| 主体多样性 | actor_diversity | 四类主体是否共同发声（熵，非话题多样性） | 协同结构 / 互动机制 |
| 传播效率（趋稳轮次） | diffusion_round | 形成稳定传播所需 Round | 比较策略扩散速度 |

S0 数值仍来自正式结果缓存；页面强调相对坐标，非预测真值。

## 图表替换原因

| 原组件 | 处理 | 原因 |
|:--|:--|:--|
| S0 现实基线画像 | **删除** | 与指标卡重复，强化 Dashboard 感 |
| 主体雷达图 | **替换**为四类画像卡片 | 雷达维难以直接回答“为何设计为不同 Agent”；卡片含真实文本与参数抽象 |
| 热力图 | **保留并改语义** | 明确 From/To；对角线=同类互动；可切换显示 “—” |

文本案例来自 `annotation/annotation_confirmed.csv`（关键词过滤后写入 `data/actor_text_examples.json`）。

## 与 Agent 模型对应关系

```text
现实角色与标注行为/策略
  → behavior_probability / strategy_probability / active_probability
信息流向矩阵
  → interaction_probability（社会互动暴露抽样）
政策事实可见与接触
  → policy_knowledge_state 更新
暴露通道说明
  → 实验/实验室中的信息接触解释（正式 S0–S3 不因本页改写）
```

映射在页面底部「从传播机制到智能体模拟」模块显式给出。

## 未新增研究假设

- 未改 ABM 核心、未改正式结果、未重跑实验。
- 结论与数值均来自既有分析/画像/网络/结果文件。
